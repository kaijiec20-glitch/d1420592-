問題一：為什麼桌遊費用以 3 人計算？直接拆成 list 與轉成 set 有何不同？
1. 為什麼以 3 人計算？
在測試一中，桌遊的原始輸入是 " Amy, Ben, amy, Cora "。

經過我們的前處理：去除所有空格並全部轉為小寫。
處理後的資料變成："amy,ben,amy,cora"。
在這之中，amy 出現了兩次。在名單整理與費用收取的業務邏輯中，同一個人不應該重複收費，因此重複的 amy 只會被計算一次。去重後的名單為 ['amy', 'ben', 'cora'] 共 3 人，費用則以 3 人計算（3 × 120 = 360 元）。

問題二：測試二（您提及的測試三）中，為什麼只有 3 位不同的人，報名人次卻是 4 人次，而總應收費用與不重複邏輯的關係是什麼？

1. 為什麼是 4 人次？
在測試組 2 中：

桌遊去重名單：{'fiona', 'gaby'} $ ightarrow$$ ightarrow$ 2 人
電影去重名單：{'gaby', 'helen'} $ ightarrow$$ ightarrow$ 2 人
報名人次 (Registrations) 的定義是「各場活動各自去重後的人數總和」，也就是不論是否有跨場重疊，只要在單一活動中報名就算 1 人次： $$\text{報名人次} = \text{桌遊人數} + \text{電影人數} = 2 + 2 = 4 \text{ 人次}$$$$\text{報名人次} = \text{桌遊人數} + \text{電影人數} = 2 + 2 = 4 \text{ 人次}$$

2. 為什麼不重複人數是 3 人？
我們使用聯集 (Union) 來計算總共參與這項活動的「不重複實體人數」： $$\text{不重複人數} = |\text{桌遊} \cup \text{電影}| = |\{'fiona', 'gaby', 'helen'}\| = 3 \text{ 人}$$$$\text{不重複人數} = |\text{桌遊} \cup \text{電影}| = |\{'fiona', 'gaby', 'helen'}\| = 3 \text{ 人}$$ 因為 Gaby 同時參加了桌遊與電影（即交集 $I = \text{桌遊} \cap \text{電影} = \{'gaby'}\%$$I = \text{桌遊} \cap \text{電影} = \{'gaby'}\%$），所以不重複計算時，她只會被算作 1 個人。

3. 為什麼總應收是 400 元？
應收費用的計算基礎是**「單場活動的參與人數」**，而不是不重複總人數。因為即使是同一個人（如 Gaby），只要她報名了兩場不同的活動，就必須各別支付該活動的費用：

桌遊費用：$2 \text{ 人} \times 120 \text{ 元} = 240 \text{ 元}$$2 \text{ 人} \times 120 \text{ 元} = 240 \text{ 元}$
電影費用：$2 \text{ 人} \times 80 \text{ 元} = 160 \text{ 元}$$2 \text{ 人} \times 80 \text{ 元} = 160 \text{ 元}$
總應付費用：$240 + 160 = 400 \text{ 元}$$240 + 160 = 400 \text{ 元}$
公式說明： $$\text{總應收費用} = (\text{桌遊去重人數} \times 120) + (\text{電影去重人數} \times 80)$$$$\text{總應收費用} = (\text{桌遊去重人數} \times 120) + (\text{電影去重人數} \times 80)$$ 即使只有 3 個不同的人，因為其中一人重複報名兩場，兩場活動皆有提供對應的服務/場地，故照常收取兩項活動的單項費用，共 400 元。
